IR 수신기 A형

R70K Type A
IR Receiver · Type A

차량의 충전 데이터를 비접촉 수신

A형 충전 노즐 하우징 내부에 설치되어 차량 IR 송신기의 적외선 신호를 수신합니다.

충전소 충전건 1개당 구성IR 수신기 1대 + 프로토콜 변환기 1대
R70K Type AIR 수신기
P70K프로토콜 변환기
연동 대상충전기 PLC

차량의 적외선 신호를 받아 충전소로 전달하고, PLC 통신 인터페이스에 맞게 변환합니다.

주요 기능
01

노즐 내 장착

A형 노즐 하우징에 맞게 설계되었습니다.

02

적외선 수신

차량 송신기에서 보내는 충전 데이터를 비접촉 방식으로 수신합니다.

03

변환기로 전달

수신 데이터를 충전 설비의 프로토콜 변환기로 전달합니다.

설치 위치A형 충전 노즐 하우징 내부

충전 노즐의 A형 하우징 안쪽에 장착합니다. 차량의 IR 송신기가 보내는 적외선 신호를 노즐 안에서 직접 받아, 충전 설비의 프로토콜 변환기로 전달합니다.

설치 전 확인 사항

  • 호환A형 충전 노즐 하우징에 맞게 설계되었습니다. 노즐 호환성을 먼저 확인하세요.
  • 크기64.4 × 34.7 × 41.2 mm입니다. 하우징 안의 장착 공간을 확인하세요.
  • 전원·환경5 V DC, 사용 온도 −40 ~ +80 °C입니다.
  • 방폭본질안전 방폭이 적용된 모델입니다.
