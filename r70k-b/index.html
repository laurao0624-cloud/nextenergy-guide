IR 수신기 B형

R70K Type B
IR Receiver · Type B

B형 노즐을 위한 적외선 수신

B형 충전 노즐 하우징 내부에 설치되어 차량 IR 송신기의 데이터를 프로토콜 변환기로 전달합니다.

충전소 충전건 1개당 구성IR 수신기 1대 + 프로토콜 변환기 1대
R70K Type BIR 수신기
P70K프로토콜 변환기
연동 대상충전기 PLC

차량의 적외선 신호를 받아 충전소로 전달하고, PLC 통신 인터페이스에 맞게 변환합니다.

주요 기능
01

B형 노즐 대응

B형 노즐 하우징에 맞는 형태로 설계되었습니다.

02

비접촉 통신

차량 송신기에서 보내는 적외선 신호를 수신합니다.

03

시스템 연동

수신 데이터를 프로토콜 변환기로 전달해 충전기 제어기와 연동합니다.

설치 위치B형 충전 노즐 하우징 내부

충전 노즐의 B형 하우징 안쪽에 장착합니다. 차량의 IR 송신기가 보내는 적외선 신호를 노즐 안에서 직접 받아, 충전 설비의 프로토콜 변환기로 전달합니다.
