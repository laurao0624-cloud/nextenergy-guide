Protocol Converter

차량 데이터를 충전기 PLC로

IR 수신기에서 받은 차량 데이터를 충전기 PLC가 사용할 수 있는 통신 형식으로 변환합니다.

충전소 충전건 1개당 구성IR 수신기 1대 + 프로토콜 변환기 1대
R70KIR 수신기
P70K프로토콜 변환기
연동 대상충전기 PLC

차량의 적외선 신호를 받아 충전소로 전달하고, PLC 통신 인터페이스에 맞게 변환합니다.

주요 기능
01

충전 안전 제어

압력·온도 변화에 따라 충전을 제어해, 온도 급상승으로 인한 용기 사고를 예방합니다.

02

PLC 연동

고객의 PLC 통신 사양에 맞춰 수신 데이터를 변환합니다.

03

충전 상태 모니터링

충전 상태를 모니터링하고 외부 시스템과 연동할 수 있습니다.

04

국제 표준 준수

충전 안전 표준 SAE J2601과 통신 표준 SAE J2799를 따릅니다.

05

맞춤 대응

펌웨어와 회로를 직접 설계해 규격 변경과 기능 확장에 빠르게 대응합니다.

설치 위치충전 설비의 제어반

충전 설비의 제어반 안에 설치합니다. 충전 노즐 속 IR 수신기가 받은 차량 데이터를 이곳에서 충전기 PLC가 사용할 수 있는 통신 형식으로 바꿔 전달하므로, 수신기와 충전기 PLC 사이를 잇는 중간 장치입니다.
